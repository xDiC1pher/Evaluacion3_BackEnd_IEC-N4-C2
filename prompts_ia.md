# Registro de Apoyo - Inteligencia Artificial

## Consultas y Tareas Solicitadas
1. **Modelado de Base de Datos:** Se solicitó a la IA generar los modelos relacionales de Django (`Tutor`, `Mascota`, `Veterinario`, `Cita`, `FichaClinica`, `Recordatorio`) basados en los requerimientos del Proyecto 1.
2. **Generación de API REST:** Se instruyó la creación de Serializers y ViewSets con Django REST Framework (DRF) para todas las entidades clínicas.
3. **Interfaz de Usuario y Seguridad:** Se pidió estructurar un contenedor base HTML con Bootstrap y una vista de Panel Médico con control de sesiones y redirección al Django Admin.
4. **Interceptores Globales:** Se solicitó codificar vistas personalizadas para devolver respuestas JSON estructuradas ante errores HTTP 404 y 500.
